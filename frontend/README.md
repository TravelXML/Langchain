# Dashboard frontend

Vite + React + TypeScript + Recharts dashboard for the Job Automation
Platform (Phase 8). See the repository root [`README.md`](../README.md#running-the-dashboard)
for how to run this alongside the backend, and [`ARCHITECTURE.md`](../ARCHITECTURE.md)
for how it fits into the rest of the system.

```bash
npm install
cp .env.example .env
npm run dev      # http://localhost:5173
npm run build    # type-checks (tsc -b) then builds to dist/
npm run lint
```
